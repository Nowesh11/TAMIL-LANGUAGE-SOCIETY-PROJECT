# Media Optimization Guidelines for Tamil Language Society Website

To ensure the best user experience, fast loading times, and optimal performance across all devices, please follow these media guidelines when uploading images and videos.

## 1. General Guidelines
- **Formats**: 
  - Images: WebP (recommended), JPG, or PNG.
  - Videos: MP4 (H.264 encoding).
- **Naming**: Use descriptive, lowercase filenames with hyphens (e.g., `annual-general-meeting-2024.webp`).
- **Compression**: Always compress images before uploading using tools like TinyPNG or Squoosh.

## 2. Image Specifications

| Component Type | Recommended Resolution | Max File Size | Aspect Ratio |
| :--- | :--- | :--- | :--- |
| **Hero Background** | 1920 x 1080 px | 500 KB | 16:9 |
| **Team Member Photo** | 400 x 400 px | 100 KB | 1:1 (Square) |
| **Project Featured Image**| 800 x 600 px | 200 KB | 4:3 |
| **Gallery Images** | 1200 x 800 px | 300 KB | Various (3:2 or 4:3) |
| **Logos / Icons** | 200 x 200 px | 50 KB | 1:1 |
| **Posters / Banners** | 1200 x 400 px | 250 KB | 3:1 |

## 3. Video Specifications

| Usage Type | Recommended Resolution | Max File Size | Duration |
| :--- | :--- | :--- | :--- |
| **Hero Background Video**| 1280 x 720 (720p) | 5 MB | 15-30 seconds |
| **Project Showcase** | 1920 x 1080 (1080p)| 20 MB | 1-3 minutes |
| **Event Highlights** | 1920 x 1080 (1080p)| 50 MB | 3-10 minutes |

*Note: For long videos (over 10 minutes or 50MB), it is highly recommended to upload them to **YouTube** or **Vimeo** and use the embed link instead of direct upload.*

## 4. Why these limits?
1. **Speed**: Larger files slow down the website, leading to a poor user experience.
2. **SEO**: Search engines like Google rank faster websites higher in search results.
3. **Storage**: Keeping file sizes small reduces server costs and ensures the system remains efficient.
4. **Mobile Users**: Many users browse on mobile data; large files consume their data quickly and load slowly on 4G/5G connections.
